Decision models

Explainable, prioritised rule sets. The first matching rule (by priority) wins.

Define a new model (JSON)

Register or replace a model. Operators: eq, ne, gt, gte, lt, lte, in, not_in, contains; logic: all / any.

Run a decision

Execute a model against input data and inspect the explainable trace.

Orchestrate a decision flow

Chain decision services into a flow. Each step's outcome is written to the shared context as <service>_outcome; a mapper feeds it into the next step.
